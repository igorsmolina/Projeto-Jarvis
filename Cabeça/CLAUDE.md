# Instruções para o Claude

Este vault é meu banco de contexto. Leia antes de pedir que eu repita algo.

## Início de sessão
1. Ler [[_index]].
2. Ler só a nota de `projetos/` do projeto em que estamos trabalhando.
3. Design: ler `design/tokens.md` só se a tarefa envolver UI.

## Não fazer
- Não ler `decisoes/` nem `reunioes/` sem eu pedir.
- Não guardar senhas, chaves de API, tokens ou dados pessoais aqui.
- Não inventar: se a nota não diz, responder "não está na nota".

## Ao terminar uma tarefa
Sugerir a atualização da nota do projeto (status, próximo passo, data).

## Formato das notas
Curtas, específicas, fatos verificáveis, com links. Datas em AAAA-MM-DD.
- Decisão: `decisoes/AAAA-MM-DD-titulo.md` — data, contexto, decisão, motivo.
- Reunião: `reunioes/AAAA-MM-DD-titulo.md` — data, participantes, decisões, próximos passos.
- Ideias soltas: `inbox/`, revisado semanalmente.
